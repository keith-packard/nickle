= Commands

The following are commands that the Nickle interpreter understands, not actual language constructs.
They may be issued only at the top level.

== Expressions

If an expression is issued at the top level, such as `3**4` or
``100!``, its value is printed to standard output.  If the expression
ends with a # sign and another expression, its value is printed in
whatever base the second expression evaluates to.

----

$ nickle
> 10!
3628800
> 3**4
81
> 3**4 # 3
10000
>
----

Statements, from expressions terminated by semicolons to complicated control structures, are executed but have no value to print.
Statements are not commands but actual syntax, so they may be used in scripts.
A newline ends a command, except inside parentheses, brackets, or braces, or partway through a control statement such as `for` or `if`.
There, Nickle reads more lines, prompting with `+`, until the command is complete, e.g.

----

$ nickle
> int x = (1 +
+ 2);
> x
3
>
----

== Quit

The `quit` command exits Nickle.
An optional argument specifies the return value.

----

$ nickle
> quit
$
----

== Print

The `print` command provides information such as visibility, type, and value, about a name.
It need not be the name of a variable; functions, namespaces, etc.
may also be printed.

----

$ nickle
> int x = 2;
> print x
global int x = 2;
> print String::length
public int length (string)
    /*
     * int length (string s)
     *
     * Return the number of characters in 's'.
     */ <builtin>
> void function hello() { printf("hello, world\n"); }
> print hello
void hello ()
{
    printf ("hello, world\n");
}
>
----

== Undefine

A defined name can be undefined.
The `undefine` command takes several names, separated by commas, and stops at the first one it can't find, e.g.

----

$ nickle
> print x
"x": name not found
> int x = 0;
> print x
global int x = 0;
> undefine x
> print x
"x": name not found
>
----

== Loading files

The `load` command evaluates the file it names, like the `-f` flag, and `library` finds the file in Nickle's library path, like the `-l` flag.
Unlike those flags, an error in such a file, or a file that can't be found, is reported and Nickle continues.

----

$ nickle
> load "nosuch.5c"
Cannot load "nosuch.5c": No such file or directory
> library "nosuch.5c"
Cannot load library "nosuch.5c": not found in "/usr/share/nickle"
>
----

The `autoload` command loads the library for each namespace it names, unless the namespace is already defined.
The library's file name is the namespace's name in lower case, with a dash before each capital letter that follows a lower-case one, and `.5c` appended, so `PRNG` comes from `prng.5c`.
The `autoimport` command does the same and then imports each namespace, and `reimport` loads the libraries even when the namespaces are already defined.

----

$ nickle
> autoimport PRNG
> randint (6) < 6
true
>
----

== Edit

The `edit` command invokes `$EDITOR` on the name given as an argument.
This is particularly useful to change a function while in interactive mode.

----

$ nickle
> void function hello() { printf("hello, world\n"); }
> edit hello
49
3
    printf ("hello, world\n");
c
printf ("goodbye, cruel world\n");
wq
53
> print hello
void hello ()
{
    printf ("goodbye, cruel world\n");
}
>
----

== History

The `history` command retrieves the values of the last ten expressions.
With an argument, it instead retrieves that many of the most recent values.
With two arguments, it retrieves the specified range in history.

----

$ nickle
...
> history
$177    5
$178    0
$179    12
$180    12
$181    -2
$182    2
$183    2
$184    0
$185    10
$186    32
> history 3
$184    0
$185    10
$186    32
> history 180,185
$180    12
$181    -2
$182    2
$183    2
$184    0
$185    10
----

These history items may be named and used directly:

----

> $180 ** 2
144
>
----

== Char

The `char` command prints each code point it is given in decimal and hexadecimal, with the character it encodes.

----

$ nickle
> char 0x263a
9786 0x263a: "☺"
>
----
