= Strings

Unlike in C, strings in Nickle are not arrays of or pointers to
individual characters.  Consistent with its pattern of providing
primitive datatypes for things that make sense (e.g. `file`
instead of integer file handles), Nickle provides the `string` type.
This has several interesting differences from C-style strings:

* In Nickle, strings are immutable--individual characters may not be changed.
* Strings hold Unicode characters, not bytes, and may contain any of
  them, including NUL.


== Operators

Several operators have been overloaded to allow sane manipulation
of strings: `+`, array subscript (`[]`), and the comparison operators.

=== Subscripting

Although they are not arrays of characters, it is often useful to
access a string a character at a time; the array subscript operator
has been overloaded to allow this.  For example:

----
> string s = "hello, world";
> s[0]
104
> s[1]
101
> s[2]
108
> s[3]
108
> s[4]
111
>
----

Those are the Unicode code points of each character, which for ASCII
characters are their ASCII codes.  Each element is a whole character,
however many bytes it takes; see
<<_unicode_and_characters_vs_bytes,Unicode and characters vs. bytes>>
in the I/O section.  So `"héllo"[1]` is 233, and the string's length
is 5.  The String namespace provides `new` to create a string from
these code points:

`string new(int c)` +
`string new(int[*] cv)`

For instance,

----
> String::new(s[0])
"h"
----

=== Concatenation

On strings, `+` is the concatenation operator. For example,

----
> string s = "hello", t = "world";
> s = s + ", ";
> t += "!";
> s+t
"hello, world!"
----

=== Comparison

`==`, `!=`, `<`, `+<=+`, `>`, and `+>=+` compare strings character by
character, as C's `strcmp` does:

----
> "abc" < "abd"
true
> "b" > "abc"
true
----

== String namespace

In addition, the String namespace provides several useful functions
that facilitate using strings, including the following.

=== Length

`int length ( string s )`

Returns the number of characters in ``s``.
For example,

----
> String::length ( "hello, world" )
12
>
----

=== Index

`int index ( string t, string p )` +
`int rindex ( string t, string p )`

Returns the index of the first occurrence of the substring `p` in
``t``, or -1 if `p` is not in ``t``; `rindex` returns the last
occurrence instead.  For example,

----
> String::index ( "hello, world", "or" )
8
> String::index ( "hello, world", "goodbye" )
-1
> String::rindex ( "hello, world", "o" )
8
----

=== Substr

`string substr ( string s, int i, int l )`

Returns the substring of `s` which begins at index `i` and is `l`
characters long. If `l` is negative, returns the substring of that
length which precedes `i` instead. For example,

----
> String::substr ( "hello, world", 8, 2 )
"or"
> String::substr ( "hello, world", 8, -4 )
"o, w"
>
----

=== Other functions

The String namespace also provides `split` and `wordsplit`, which
break a string into an array of strings at separator characters;
`chomp`, which trims white space from both ends, and `chump`, which
trims trailing newlines; `reverse`; `dirname`, which returns the
directory part of a path; and `parse_csv`, which splits a line of
comma-separated values.

----
> String::split ( "a,b,c", "," )
(string [...]) {"a", "b", "c"}
> String::chomp ( "  hi  " )
"hi"
----
